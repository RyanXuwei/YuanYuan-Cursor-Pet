# 1.10.0 驗證紀錄

2026-11-16 — 1.10 狗籠名單：實際 Chromium 載入含 service worker 的套件，透過已註冊的選單處理函式測試加入／移除。同主機名稱的不同路徑與 HTTP/HTTPS 分頁立即隱藏，其他網域及子網域不受影響；重新載入仍隱藏，且沒有啟動角色動畫；移除不覆蓋全域關閉；面板移除、重複加入、並行寫入及五種語言皆通過，manifest 與頁面錯誤為 0。五語切換、語言記憶與舊設定相容，以及播放器／整頁／iframe／瀏覽器全螢幕隱藏回歸亦通過。未在使用者實體 Chrome 操作原生右鍵選單。

2026-11-15，以 Playwright Chromium 無介面環境實際載入未封裝擴充功能，使用合成 HTTP 網頁，沒有讀取使用者瀏覽資料。
