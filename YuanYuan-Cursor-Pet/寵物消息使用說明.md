# 寵物消息使用說明（v1.13.0）

## 開啟與閱讀

1. 開啟圓圓設定，在「自訂寵物外觀」下方找到「圓圓叼回來的消息」。
2. 勾選「啟用每日寵物消息」，在 Chrome 提示中允許 Google News。拒絕時保持關閉；舊有寵物互動不受影響。
3. 有未讀時，圓圓嘴邊出現小報紙。點報紙打開卡片，或點設定的「閱讀寵物消息」開啟獨立頁。
4. 點標題另開原文，同時標記已讀；也能按「標為已讀」。讀完兩則後報紙消失。
5. 可按「再找消息」，每次最多兩則、略過已讀，至少間隔一分鐘。無合適消息時不補舊聞。
6. 關閉開關停止新的 RSS 請求並隱藏消息，快取和已讀保留供下次使用。

## 當日、語言與排序

以電腦當地日期及時區判斷「當日」，不是只看最近 24 小時。文章發布日期在今天才符合；這不是活動舉辦日期。每天第一次在一般網頁／設定／閱讀頁使用時更新，Chrome 未開啟時不另排背景工作。持續開著的寵物分頁每分鐘只檢查日期，換日時才再次請求快取／更新。

- 繁體中文：台灣新聞版，繁體關鍵字。
- 簡體中文：台灣新聞版，簡體關鍵字；標題可能為繁體。
- English：美國版。
- 日本語：日本版。
- 한국어：韓國版。
- 自動：依 Chrome 介面語言解析為上述之一，不使用位置、目前網站或瀏覽紀錄。

依序搜尋「寵物時事、寵物旅遊、寵物展覽、獸醫相關閱讀」，規則排序取最多兩則；第一組足夠就不查後面的組別，單次最多四個 RSS 查詢。各語言有獨立關鍵字，排除重複、昨天／未來日期、無效連結、部分促銷或 PET 塑膠／英文比喻誤命中。這是關鍵字匹配，仍可能有不相關文章；完整字詞見 news-core.js 的 editions 與 category。

## 本機儲存與網路

newsEnabled 為開關；newsCache 依五種語言保存目前最多兩則及更新狀態；newsRead 最多 300 個已讀標記，標記時清理 14 天前項目。只用 chrome.storage.local，不使用 sync，不由開發者伺服器收集。不同電腦、Chrome 設定檔各自運作；同一設定檔的分頁共享。解除安裝會移除本機資料。

啟用並授權後，背景程序才請求 https://news.google.com/rss/search，送出固定主題關鍵字、新聞版與語言。Google 仍會收到 IP 等一般網路技術資訊；請求不夾帶 Cookie、目前頁面網址、頁面內容或已讀狀態。點原文另開外部網站後，適用該網站政策。沒有 API Key、AI 搜尋或遠端程式碼。

## 不說話、不增加圖片序列

報紙為 HTML／CSS，與圓圓位置及移動朝向連動。閱讀卡固定在畫面內；靠邊會調整。拖曳拎起、睡覺、泡泡、進食、取球及邊緣偷看時暫藏；狗籠、全域關閉與全螢幕隱藏仍生效。標記都是資訊來源及新聞，不是圓圓台詞。

## Chrome 本機 AI（選用）

獨立閱讀頁可檢查 Chrome Translator API，對標題做本機翻譯。搜尋／選文永遠使用固定規則。僅 availability() 為 available 才建立翻譯工作；downloadable、downloading、unavailable 或不支援時只提示，不自動下載模型。原文仍顯示；翻譯不代表醫療知識正確，也不會讀取全文或瀏覽頁面。

測試環境的模型尚未備妥，沒有下載；已用模擬就緒模型驗證按鈕流程，不代表此電腦已完成真實模型翻譯驗證。
