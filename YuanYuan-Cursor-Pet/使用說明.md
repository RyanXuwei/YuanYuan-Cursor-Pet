# YuanYuan Cursor Pet 1.12.0

## 安裝或更新

推薦從 Chrome 線上應用程式商店安裝：開啟 https://chromewebstore.google.com/detail/yuanyuan-cursor-pet/feodmaldlbhnchhncfacjnpeljcgidap ，按「加到 Chrome」。商店版會自動更新。安裝後重新整理一般網頁，從 Chrome 工具列的「游標＋橘色小球」圖示開啟設定。

手動安裝（GitHub Release ZIP）：

1. 解壓縮 ZIP 到固定資料夾。
2. 開啟 Chrome 的 chrome://extensions，打開「開發人員模式」。
3. 選「載入未封裝項目」，選擇包含 manifest.json 的 YuanYuan-Cursor-Pet 資料夾。
4. 重新整理一般網頁，從 Chrome 工具列的「游標＋橘色小球」圖示開啟設定。

手動版更新時，可將新檔案覆蓋原安裝資料夾後在擴充功能頁按重新載入，再重新整理網頁；若改用新資料夾，請移除或停用舊項目後載入新資料夾，避免同時啟用兩版。請保留安裝資料夾。商店版與手動版請擇一安裝，同時啟用會出現兩隻圓圓。

## 自主活動，不用指令選單

設定只有開關、大小、行動方針、允許出現的行為與語言。沒有直接選動作、重播按鈕或狗狗說話的文字泡泡。

| 行動方針 | 傾向 | 一個行為結束後通常休息 |
| --- | --- | --- |
| 乖巧安靜 | 安靜注視、休息、輕度跟隨 | 20–34 秒 |
| 親人撒嬌 | 跟隨、靠近討摸、歪頭陪伴 | 13–24 秒 |
| 活潑好奇 | 散步、嗅聞、探索、玩球 | 8–17 秒 |
| 調皮搗蛋 | 衝刺、跳跳、繞圈、探頭、玩球 | 5–12 秒 |

每個行為另有不同冷卻時間。設定面板會顯示目前方針的基礎權重占比及最短冷卻秒數；實際抽選會排除未勾選、冷卻中的行為，並依閒置、視窗大小和飯碗狀態調整。這不是保證每幾秒一定做指定動作。

全部行為取消勾選時，圓圓只會安靜站著，仍可拎起放下及操作玩具。

## 直接互動

- 拎起圓圓：按住圓圓拖曳，使用固定一張懸空姿勢；滑鼠左右移動時會自然晃動，停住後逐漸平穩。放開後會向下落約 18–45 px 再著地，接近底邊時會縮短落距，然後恢復自主活動。只有圓圓、球、飯碗及泡泡本身接收點擊。
- 投球：拖住橘色球再放開。水平速度依放手時甩動的快慢與方向；球只會碰左右邊界反彈，不會撞上下邊界。球會落到固定的地板高度（距畫面底部 96 px），之後彈跳高度為預設值，與放手高度無關，最後在地板上滾停。直接按球或鍵盤聚焦後按 Enter，也能拋球。
- 撿球：允許「丟接球」時，投球會引起圓圓追逐；球慢下來後才拾起，帶回投球時圓圓所在的位置並放下。取消該行為後，球仍可玩，但圓圓不會去撿。
- 餵零食：點飯碗，會換成有餅乾的飯碗。飯碗初始放在右下角，也可按住拖到其他位置；拖曳不會誤加零食。允許「吃零食」且冷卻結束時，圓圓會走過去吃，吃完飯碗清空。若尚在做其他事，可能會等一會；重複點滿碗不會無限堆食物。吃飯中把碗拖走會立刻停止咀嚼，零食保留；放下後圓圓會走到新位置繼續吃。
- 以上是物件互動，不是直接命令動作的選單。

球採簡化物理運算：重力、固定地板、預設彈跳高度、左右邊界反彈與滾動摩擦，並以固定細分時間步進確保不同畫面更新率結果一致；不會撞網頁文字、按鈕或真實 Windows 視窗框。

## 圓圓的行為

跟隨、逃跑、繞圈、跳跳、衝刺、睡覺、角落探頭、搖擺、嗅聞、探索、丟接球、吃零食、散步、小便、生氣、吠叫、撒嬌、默默看著你，魚眼大頭探看、泡泡漂浮，以及前腳挖洞。

- 移動有獨立跑步圖集，散步有慢步圖集，向左會轉身，停下不再原地跑。
- 睡覺會閉眼趴下。閒置至少 35 秒後才可能被自動選到；移動滑鼠會醒來。
- 小便會先靠邊、抬腿，再出現短暫淡黃色尿流與尿漬，尿漬約 8 秒淡出。小便有較長冷卻，也可完全排除。
- 生氣會轉頭；吠叫有開口動作，但本版沒有音效或文字「汪汪」。
- 撒嬌會靠近、歪頭、伸前腳，可出現小愛心，沒有文字泡泡。
- 默默看著你是安靜坐姿及眨眼，沒有使用相機。
- 魚眼大頭探看會先跑到畫面前方，再放大成廣角大頭、歪頭看你，停留後縮回正常大小；小視窗不會選到此行為。

## 限制與隱私

- 僅在一般 HTTP/HTTPS 網頁可視區活動，無法跑到網址列、其他程式或 Windows 桌面。
- Chrome 設定、商店、新分頁及部分內建 PDF 頁等受保護頁面無法顯示。
- 只使用本機儲存權限與一般網頁內容腳本；無外部請求、伺服器、追蹤或遠端程式碼。
- 不讀取網頁文字、輸入欄位、相機或麥克風。設定存於本機。
- 分頁隱藏時暫停繪製與物理運算；恢復後限時行為可能按已過時間結束。
- 系統啟用減少動態效果時減少逐格、跳躍與連續移動；球仍保留物理反應。
- 素材為 AI 生成的視覺近似，並非精確動物運動學或真實情緒模擬。
- 尚未逐一驗證所有第三方網站與長時間使用情境。GPT 的寵物選擇不會被變更。

## 1.5 新增日常

- 泡泡漂浮：圓圓被半透明肥皂泡包起來，在畫面中緩慢漂浮。戳一下泡泡就會破掉，圓圓輕輕落地；也支援鍵盤聚焦泡泡後按 Enter。約 22 秒沒有互動會自行破掉，避免一直被困住。可在允許行為中排除。
- 邊緣藏身偷看：先跑到左、右或下方邊緣，身體藏出可視區，再露出頭偷看。游標靠近會縮回，最後自己跑回來。這是網頁內的裁切效果，不會真的跨到 Chrome 外。
- 前腳挖洞：先走到位置、嗅聞，再用專用四格素材交替前腳連續挖；小洞與土屑是覆蓋效果，不會破壞網頁內容，結束後約 6.5 秒消失。
- 三項行為均依方針、允許清單、權重與冷卻時間決定是否發生，沒有直接動作指令。

舊版若原本允許全部行為，會自動加入泡泡與挖洞；若曾自訂排除行為，會保留你的清單，請自行勾選想新增的項目。泡泡與挖洞在過小的畫面中不會被選到。

## 1.6 多語切換

- 支援繁體中文、简体中文、English、日本語、한국어。
- 設定面板最下方的「語言」可切換；預設「跟隨瀏覽器語言」：繁中（台、港、澳）→ 繁體中文，其他中文 → 简体中文，日文、韓文對應各自語言，其餘語言 → English。
- 切換後設定面板立即更新，已開啟的網頁中，球、飯碗、泡泡與圓圓的提示文字和無障礙標籤也會同步更換，不需重新整理。
- Chrome 擴充功能管理頁及工具列提示的名稱與說明，依 Chrome 介面語言顯示（_locales），不受面板內語言選項影響。
- 圓圓沒有說話，因此網頁上不會出現任何翻譯文字泡泡。
- 舊版設定沒有語言欄位時，自動使用「跟隨瀏覽器語言」，其他設定保留。

## 1.7.1 圖樣大小平衡

各組逐格圖原本由不同批次生成，圓圓在跑步、睡覺、被抓起時明顯比站姿小。本版以頭部大小為基準，統一各圖集的比例，並以腳底基準線為錨點縮放，切換動作時不會忽大忽小或上下跳動：

| 圖集 | 調整倍率 |
| --- | --- |
| 站姿／待機（yuanyuan.png） | 0.90 |
| 生氣、吠叫、撒嬌、注視（moods） | 0.90 |
| 跑步（run） | 1.30 |
| 睡覺 | 1.18 |
| 吃零食 | 0.96 |
| 小便 | 1.03 |
| 散步 | 1.06 |
| 被抓起（held） | 1.17 |
| 挖洞（dig） | 不變 |

跑步受格子寬度限制最多放大到 1.30 倍，因此站姿同步縮小 10% 讓兩者接近；整體看起來比先前略小一點，可用設定中的「圓圓大小」調大。魚眼大頭探看刻意放大，不在此平衡範圍。調整前原圖保存在開發資料夾 work/sprites-before-rebalance。

## 1.8 球的大小與地板

- 球放大：直徑為圓圓大小的 0.4 倍（預設 38 px），並裁掉圖片四周空白，畫面上可見的球由約 22 px 變為約 36 px。
- 固定地板：地板線設在距畫面底部 96 px（視窗很矮時改為不超過視窗高度 25%），球靜止時停在這條線上，不會掉到畫面最下方。拖曳球也不能拉到地板以下。
- 垂直移動為預設高度：在地板上方放手會落下；著地後第一次彈跳約 90 px，之後每次減半，約五次後停止彈跳並滾停。甩動的上下速度不影響高度，也不會撞到畫面頂端。
- 只有左右反彈：碰到左、右邊界會彈回並損失部分速度。
- 圓圓撿回球放下時，球會小跳一下後停在地板上。

## 1.8.1 球與飯碗隨大小縮放

- 球直徑固定為圓圓大小的 0.4 倍，不再有上下限：48 px 時約 20 px、96 px 時 38 px、160 px 時 64 px。
- 飯碗寬度為圓圓大小的 0.6 倍：48 px 時 29×25、96 px 時 58×50、160 px 時 96×83。調整大小時飯碗以右下角為基準縮放，不會跑出畫面。
- 圓圓去吃零食時，離碗遠會用跑的，接近碗（約 1.5 個身長內）才慢走；修正小尺寸時走太慢、還沒走到就放棄的問題。

## 1.9 全螢幕時自動隱藏

以下情況圓圓、球、飯碗會一起隱藏，動畫與物理運算暫停；離開全螢幕後自動出現並繼續活動：

- 影片或播放器全螢幕（例如網頁影片按全螢幕鍵）。
- 整頁全螢幕，例如 YouTube 全螢幕。
- 網頁中嵌入的影片（iframe，例如嵌入的 YouTube）全螢幕。
- 瀏覽器全螢幕模式（F11）。偵測依 Chrome 回報的全螢幕顯示模式（display-mode: fullscreen）。

隱藏期間若正在拎起圓圓、拖球或拖碗，該動作會取消。


## 1.10 狗籠名單

在一般網頁上按右鍵 → 狗籠名單 →「將此網站加入狗籠名單」，Pet 與其球、飯碗、特效會立即隱藏；之後造訪同網域仍隱藏。右鍵 →「將此網站移出狗籠名單」可恢復；設定面板的「狗籠名單」也能逐筆移除。

名單以目前分頁的網站主機名稱為單位，例如 example.com 的所有路徑、HTTP/HTTPS 和連接埠都適用；子網域如 www.example.com 與 shop.example.com 各自管理。右鍵連結時處理的是目前網站，不是連結目的地。

名單只保存在本機，不記錄完整網址、路徑或查詢參數，不自動建立瀏覽歷程。加入名單的網站不啟動角色動畫。移出名單不會強制打開原本已關閉的 Pet，也不會覆蓋全螢幕隱藏設定。

新增 contextMenus 權限僅用來建立原生右鍵選單；storage 同時儲存狗籠名單。五種語言的選單與面板均已支援。
